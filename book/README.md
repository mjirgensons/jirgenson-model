# Book files: Steer, Don't Guess (English edition 1.1)

Working files of the book, kept separately from the public companion files in the repository root (canon and prompt).

- `EN_1.1/source/`: Pandoc Markdown source of the book (edition 1.1).
- `EN_1.1/kindle/`: Kindle EPUB for KDP.
- `EN_1.1/print/paperback/`: paperback manuscript and cover (6 x 9 in).
- `EN_1.1/print/hardcover/`: hardcover manuscript and cover (KDP case laminate, 6 x 9 in, Premium color), the KDP cover template and the hardcover plan.

Do not make these files public: they are the full book.
