# The Jirgenson Model: canon and operating prompt for a digital assistant

English · [Русский](README.ru.md)

Companion files to the book by Martin Jirgenson "Steer, Don't Guess. Setting Priorities, Reading the Numbers and Correcting Course in Business and Life. The Jirgenson Model" (English edition, 2026; first edition in Russian, 2026).

## Files

English edition:

- `jirgenson_canon_v1.0_en.txt`: the canon of the model (Appendix H of the book). A compact rulebook of the model in English, sections §0 to §16, canon-id JMC-1.
- `jirgenson_prompt_v1.0_en.txt`: the operating prompt (Appendix I of the book). It tells the assistant how to work with the canon. It is written in English, and the assistant replies in the language you write in.

Russian edition: `jirgenson_canon_v1.0.txt` and `jirgenson_prompt_v1.0.txt` (see [README.ru.md](README.ru.md)).

## How to use

1. Download both files (Download or Raw, then save).
2. Open a new conversation with a language model (an assistant).
3. Attach the canon file to the message or paste its full text.
4. Send the prompt as your first message.
5. Describe your situation in plain words as your second message. Sample messages are given in Appendix I of the book.

Without the canon the assistant will not start and will ask for it: this is by design.
