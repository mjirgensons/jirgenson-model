# Working notes

These notes were kept while the experiment ran, in the working language of the author, and are published here in English translation made by Claude, sentence by sentence, without changes to content. Every number in each translated file was checked by script against the original. Quotations of the author's instructions and of scenario or answer wording are given in English.

Edits other than translation, all made for this record:
- passages about the separate round-4 test, which is not part of this record, were removed; where the round-5 error analysis used v1.3-c judge records from that run, they are referred to as "an additional judging run of v1.3-c that is not part of this record";
- the range of the judging-context effect, previously computed over all runs, is given without that run (+1.1 … +2.7);
- in the run log, the name of the author's computer is replaced with "[computer name removed]", and paths on the author's computer with "[local archive]";
- paths to the original working folders are mapped to the folders of this record where possible (`iter_N/` corresponds to `roundN/`), and the "location" paragraph of the final results note points to this record.
