## Step 1. Recomputed key numbers

- Average income: (6,100 + 6,900 + 6,500) / 3 = 19,500 / 3 = **€6,500**.
- Biggest client (55%): 0.55 × 6,500 = **€3,575**. Second client (15%): **€975**. Everyone else (30%): **€1,950**.
- After the second client leaves: 6,500 − 975 = **€5,525**.
- Biggest client's share after the loss: 3,575 / 5,525 = **64.7% ≈ 65%**.
- Gap to €10,000: 10,000 − 5,525 = **€4,475**, which is **+81%** in 12 months (a linear ramp is about €373 a month).
- If the biggest client also left: 5,525 − 3,575 = **€1,950**.
- Biggest client's share at €10,000 if unchanged: 3,575 / 10,000 = **35.75% ≈ 36%**.
- Not given: reserve, monthly costs, contract terms, pipeline, capacity, and whether €6,500 is revenue or profit.

Counting method: I count words in the assistant text, including headings. I count questions by the H2 rule, which counts question marks addressed to the person. I apply the same count to M4 and F2 so that the number of questions has one value throughout this judgment.
