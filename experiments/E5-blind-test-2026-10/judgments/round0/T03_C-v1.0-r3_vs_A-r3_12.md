## Step 1. Recomputed key numbers

- Revenue €18,000 = 120 members × €150. Costs €15,500, of which variable €3,600 (= €30 per member = 20 % of current revenue) and fixed €11,900.
- Profit now €2,500/month; margin 2,500 / 18,000 = **13.9 %**.
- Contribution per member: €120 at €150; €90 at €120.
- Price −20 % (€120), same 120 members:
  - Gold route (variable as 20 % of revenue): 14,400 − 11,900 − 2,880 = **−€380/month**.
  - Task-text route (variable "varies with the number of members", so €30 per member stays): 14,400 − 11,900 − 3,600 = **−€1,100/month** (−7.6 %). The task wording supports this route, so I accept it as a correct alternative. Either way the conclusion is the same: a loss at the same membership.
- 25 % margin at €120:
  - Gold route: 11,900 / (1 − 0.20 − 0.25) ≈ €21,636 ≈ 180 members (+50 %).
  - Per-member route: 90n − 11,900 = 0.25 × 120n → 60n = 11,900 → n ≈ 198.3 → **199 members (+79, +66 %)**.
- 25 % margin at €150 (per-member route): 120n − 11,900 = 37.5n → n ≈ 144.2 → **145 members (+25)**.
- Break-even at €120: 11,900 / 90 ≈ 132.2 → **133 members**. Same revenue as today at €120: **150 members**. Same profit as today at €120: (11,900 + 2,500) / 90 = **160 members**.
- Sensitivity, variable ±10 %: €33/member → fixed 11,540 → 11,540 / 87 ≈ 132.6 → 133; €27/member → fixed 12,260 → 12,260 / 93 ≈ 131.8 → 132. So 132–133 holds.
- Extra €1,000/month of fixed cost: break-even cover needs 1,000/120 ≈ 8.3 → 9 members at €150, 1,000/90 ≈ 11.1 → 12 at €120. To keep a 25 % margin: 1,000/82.5 ≈ 12 at €150, 1,000/60 ≈ 17 at €120.
- Tax arrears: 9,000 / 2,500 = **3.6 months** of all current profit. This is an obligation, not a goal.
- Reserve/cash: **not given**.

Both responses use the per-member route (−€1,100; 199 members). Under the task's own wording this is correct, so neither response loses points for differing from the gold −€380/180.
