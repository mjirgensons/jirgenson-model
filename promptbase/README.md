# promptbase/

Everything related to selling the Jirgenson Model on PromptBase (and other prompt marketplaces) lives in this folder.

- `jirgenson_prompt_v1.1_en.txt`, `jirgenson_canon_v1.0_en.txt`: the two product files, byte-identical copies of the files in the repository root (book edition 1.1, Appendices H and I). The buyer receives both files and attaches them to a new conversation.
- `29_PROMPTBASE_PILNA_PRODUKTA_IERAKSTS.md`: listing package (title, description with the experiment figures and their limits, buyer guide, variables, test prompt, examples, price, tags), account steps, delivery options. Latvian with English listing texts.
- `28_PROMPTBASE_UN_IDEJU_KATALOGS.md`: marketplace assessment (traffic, fees, rules, what sells) and the catalogue of all sales ideas.

Rule: the product files here are never edited separately; when a new prompt or canon version is released in the root, copy it here and update the listing.
