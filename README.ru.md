# Модель Йиргенсона: канон и промпт для цифрового помощника

[English](README.md) · Русский

Материалы к книге Мартина Йиргенсона «Перестать гадать. Как управлять бизнесом и жизнью по приборам, а не по ощущениям. Модель Йиргенсона» (2026).

## Файлы

- `jirgenson_canon_v1.0.txt`: канон модели (Приложение H книги). Краткий свод правил модели на английском языке, разделы §0 по §16, canon-id JMC-1.
- `jirgenson_prompt_ru_v1.0.txt`: рабочий промпт для русского издания (Приложение I книги). Инструкция помощнику, как работать с каноном; отвечает помощник на вашем языке.

## Как пользоваться

1. Скачайте оба файла (кнопка Download или Raw, затем «Сохранить как»).
2. Откройте новый диалог с языковой моделью (помощником).
3. Приложите файл канона к сообщению или вставьте его текст целиком.
4. Первым сообщением отправьте текст промпта.
5. Вторым сообщением опишите свою ситуацию обычными словами. Образцы сообщений даны в Приложении I книги.

Без канона помощник не начнёт работу и попросит его: так задумано.

## Версии

Версия 1.0, октябрь 2026. Соответствует первому русскому изданию книги. Канон один для всех языков; промпт выпускается для каждого языка издания (суффикс ru, en). Обновления появляются здесь с новым номером версии; в начале каждого файла указана его версия. История изменений: `CHANGELOG.md`.
